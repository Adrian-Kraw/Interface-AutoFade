## 1.0

First release. Interface AutoFade is the Interface Fading of Aklime Mod Tools as its own addon, for WoW Retail and WoW Forever. / Erste Veröffentlichung. Interface AutoFade ist die Interface Ausblendung aus Aklime Mod Tools als eigenes Addon, für WoW Retail und WoW Forever.

**EN**

* New: First release. Interface AutoFade is the Interface Fading of Aklime Mod Tools as its own addon. It works the same way.
* New: One addon for WoW Retail and WoW Forever. It detects the client by itself.
* New: The settings window opens with `/autofade` or with the minimap button.

Compatibility

* Aklime Mod Tools contains the same Interface Fading. If you use both addons, switch it off in one of them.

**DE**

* Neu: Erste Veröffentlichung. Interface AutoFade ist die Interface Ausblendung aus Aklime Mod Tools als eigenes Addon. Sie funktioniert genauso.
* Neu: Ein Addon für WoW Retail und WoW Forever. Es erkennt den Client selbst.
* Neu: Das Einstellungsfenster öffnet sich mit `/autofade` oder mit dem Minimap-Button.

Kompatibilität

* Aklime Mod Tools enthält dieselbe Interface Ausblendung. Nutzt du beide Addons, schalte sie in einem von beiden aus.
